# Atelier Board

移动端优先的服装图集生成器。用户可一次上传最多 30 张商品截图，在浏览器本地完成主体提取和双列瀑布流排版，随后导出包含所有图片的单文件 HTML。

## 特点

- 图片全程只在浏览器本地处理
- 自动识别画面中央最大的服装主体并移除浅色背景与截图界面
- 手机端双列瀑布流预览
- 支持 Web Share API；不支持时自动下载 HTML
- 纯静态文件，可直接部署至 GitHub Pages

## 本地预览

```bash
python3 -m http.server 4173
```

访问 `http://localhost:4173`。

## 适用范围

当前版本针对“浅色纯净背景、服装位于画面中央”的商品图进行优化。复杂背景、真人穿着图或与背景颜色接近的浅色服装，建议后续接入专用图像分割服务。
